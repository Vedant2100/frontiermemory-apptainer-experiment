## Reading

- Strict outcome is tied at 0/3 vs 0/3. There is no evidence that memory improves strict pass rate.
- The arms differ consistently on one thing: every B artifact met the callable interface and was graded (1/6 cases each). No A artifact got that far. Two A trials missed the callable, and one failed at import on an NLTK resource. This matches what the instruction demands ("callable interface and artifact layout used by prior implementations"), which a no-memory agent cannot know. Three of three against zero of three is suggestive at n=3, not conclusive.
- B used fewer requests and tokens on average, with wide variance.
- B's remaining failures (5/6 cases) are functional. The memory's preprocessing lessons did not carry the agent to a passing implementation.

## Limitations

- n=3 per arm, single task, single local model and harness. Not the official 15-task protocol.
- The memory is built from family-selected evidence (14 word2vec trajectories), not a whole-corpus dream run (deviation D2).
- The validity rule was amended after the no-memory smoke run and before any B trial (D5').
- A Harbor Singularity exec-timeout wrapper restores the task's 1200 s limit; earlier Singularity runs were capped at 600 s.
- The verifier is staged with network mode `public`; egress isolation is not enforced.
- Raw trajectories, generated code, memory text, and verifier output stay local and are not published.
